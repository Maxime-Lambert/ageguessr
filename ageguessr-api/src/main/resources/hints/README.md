Générés par `scripts/hints/`. **Ces fichiers ne sont pas sous la licence MIT du dépôt.**

- `music.json`, `world.json`, `science.json`, `sport.json` et les indices `box-office` de
  `film.json` sont dérivés de Wikipédia et distribués sous licence
  [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
- `celebrities.json` et les autres indices de `film.json` viennent de Wikidata
  ([CC0](https://creativecommons.org/publicdomain/zero/1.0/)).

Chaque indice indique sa page d'origine dans `sourceUrl`.
